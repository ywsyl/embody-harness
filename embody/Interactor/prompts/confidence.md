【信息可信度推理规则】
可信度判断不是对"这个解释听起来是否合理"的主观打分，而是依据以下推理规则，综合信息本身的明确程度、来源可靠性、语义歧义、逻辑推理链条以及实体指向唯一性，判断**现有证据在多大程度上足以支持该信息准确表达用户的真实意图**。

# 1. 来源层级
信息的可靠性由来源决定，判断时优先采信更高层级的来源：
- 用户当前指令：最高优先级，最可靠。
- 当前环境观测、稳定记忆：可靠。
- 近期上下文：需确认仍适用于当前任务（用户是否已修改、否定或重新指定）。
- 历史上下文：距离越远、场景变化越大越不可靠。

新旧信息冲突时，优先采用当前用户信息；被用户明确否定的信息不得作为正向证据使用。

# 2. 推理规则
- 推理是获得信息的常见方式，但**推理只保持或损失确定性，不会凭空增加确定性**：推理结果的置信度原则上不得高于推理所依据前提中的最低置信度。
  - 例："小王在 518"（0.8）+ "518 当前有人"（0.9）→ 推断"518 的人是小王"，其置信度不应超过 0.8。
- 推理链越长，确定性折损越大；推理链条中出现猜测、默认假设、模糊指代、常识补全时，确定性进一步下降。
- 直接证据优先于推理证据。

- 推理原因质量约束
  - 推理链中的每一步推断都必须有直接证据支撑，不同证据之间必须有直接关联、不得有逻辑跳跃。
  [反例] `"上下文提到甲具有特征A，此人具有特征B，推测此人是甲"` 
  - 特征A与特征B没有直接关联（如"穿红裙子"和"穿白上衣"）：这是无效推断，因保持原值，不得写入。
  - 特征A与特征B类似（如都为"穿白上衣"）：认为具有相同特征的人为同一人是逻辑谬误，只是可能正确，因此只能作为参考猜测写入，认为低置信度。
  - **跨来源实体绑定**：不得仅凭"上下文 / 历史 / 记忆中出现的人具备特征A"与"用户指令目标具备特征A"（如都穿黑色衣服）就断言两者指向同一实体；`add_reason` 不得写出"该描述与用户指令'黑色衣服的男子'指向同一实体"这类仅基于特征相似的结论。跨来源合并仅在原文有**明确同一指代**（同一姓名 / "椅子上的人"等持续固定指代）时才成立，否则保持原值或作为低置信度猜测。
  [正解] `"上下文提到甲具有特征A，此人是甲，推测此人具有特征B"` 
  - 特征B是特征A的子集（如A为"穿白上衣红裙子"，B为"穿白上衣"）：认为逻辑正确，可将推理写入，认为置信度高
  - 其它情况：根据具体信息判断

# 3. 逻辑正确性

出现以下逻辑错误时，该信息不得保留高置信度，应判为低置信度或明确标记为假设：

- **逆命题推理**：由"A → B"反推"B → A"。（"小王穿红衣服"不能推出"穿红衣服的人是小王"）
- **同属性同实体**：仅凭名称 / 地点 / 衣着 / 职位 / 类别相同就合并实体（同名 ≠ 同一人）。
- **跨来源特征匹配 ≠ 同一实体**：不得仅凭"上下文 / 历史 / 记忆中出现的人具备特征 A"与"用户指令目标具备特征 A"（如都穿黑色衣服、都戴黑框眼镜）就判定两者为同一实体，也不得在 `add_reason` 中断言"指向同一实体"。跨来源实体合并必须以原文中**明确的同一指代**为依据（同一姓名，或"椅子上的人"等持续使用的固定指代）；仅特征相似至多作为低置信度猜测（≤ 0.3），不得当作已确认事实。
- **集合关系错误**："某些 A 是 B"≠"所有 A 都是 B"；"A 属于 B 类"≠"B 类属性都适用 A"。
- **空间共现**：两实体同处一地，不能推出所有权、人物、交互、任务等关系。
- **可能性当作必然**："通常 / 一般 / 大概率"等统计关系不能转换为确定事实。
- **无依据补全缺失关系**：无证据时补全"属于 / 正在交谈"等关系。

# 4. 歧义与实体唯一性

- 信息越模糊、泛指、依赖补充解释，可信度越低；存在多个同等合理的候选解释且无法唯一确定时，应保留歧义，而不是强行选择。
- 实体身份信息的区分能力决定唯一性：
  > 唯一标识（如工号）> 多属性组合 > 单一属性 > 类别信息
- 仅凭名称或单一非唯一属性匹配实体时可信度低；多个弱属性（如"男性 + 黑发 + 穿鞋"）不能机械叠加为强证据。
- 存在多个同名实体时，仅凭名字不得保留高置信度。

# 5. 时间衰减

- 动态信息（位置、设备状态等）随时间衰减；稳定属性（姓名、身份等）衰减较慢。
- 不同时间获得的信息不能直接合并为当前事实。
  - 例：9 点"小王在 518"，11 点"小王去了会议室"，11:10 时不应仍以高置信度认为"小王在 518"。

# 6. 总体原则
1. 直接证据优先于推理证据。
2. 推理结果置信度不得无依据高于原始证据。
3. 禁止将充分条件与必要条件混淆。
4. 禁止因名称或单一属性相同直接合并实体。
5. 多个弱证据不能机械累加成强证据。
6. 推理链条越长，确定性折损越大。
7. 可能性关系不能转换为确定事实。
8. 空间共现、时间共现、类别相同均不能自动推出更强的语义关系。
9. 存在多个合理候选时，应保留歧义，而不是强行选择。
10. 无法获得可靠逻辑依据的信息，应保持低置信度或明确标记为假设。
11. 跨来源（用户指令 / 近期上下文 / 历史 / 记忆）的实体绑定不得仅凭特征相同完成，须有原文明确的同一指代，否则视为低置信度猜测。
